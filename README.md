# POHYB bez bolesti – web

Statický web podle dodaného návrhu.

## Soubory
- `index.html` – obsah webu
- `style.css` – vzhled a responzivní design
- `script.js` – drobné chování stránky
- `assets/` – logo, fotografie a mapa z dodaného návrhu

## Spuštění
Stačí otevřít `index.html` v prohlížeči.

## GitHub Pages
Po nahrání do GitHub repozitáře lze web publikovat přes Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
